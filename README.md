## What is businessOS-DE?

A Notion template suite specifically built for solo entrepreneurs in Germany, Austria, and Switzerland — with **built-in DACH-specific tax logic** that English-only templates don't address:

- Kleinunternehmer §19 UStG (DE) / §6 Z 27 UStG (AT) / CH-Grenzwert toggle
- Fahrtenbuch (mileage allowance) — 0.30 EUR/km auto-calculation
- Bewirtung (business meal) — 70% deductibility automation
- Vorsteuer (input tax) calculation per receipt
- Quarterly filter for ELSTER (German tax authority) export
